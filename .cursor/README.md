# Cursor Rules for StarRocks Debug Skills

These rules are converted from the StarRocks debug skills.

## Installation

The rules will be automatically loaded by Cursor when placed in `.cursor/rules/`.

To regenerate from the latest SKILL.md files:

```bash
./scripts/install.sh --tool cursor --target .cursor/
```
